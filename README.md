# Foot Star Awards

créer une app pour que tous les joueurs de mon équipe de foot puisse voter pour l'homme du match juste après ce match. Il faudrait que chaque joueur puisse voter pour le Choule d'Or, le Choule d'argent, le Choule de bronze et le Dommage. L'app proposerait la liste de tous les joueurs inscrits dans le club.
